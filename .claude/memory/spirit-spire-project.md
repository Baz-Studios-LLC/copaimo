**Spirit Spire** — 2D action Metroidvania at `C:\Users\jsull\Desktop\SpiritSpire\`. Player is a Spirit Shaman climbing a vertical tower; absorbs "Phantom" archetypes that modify the base spear+shield kit.

- **Engine: Godot 4.7 (GDScript).** Binary lives on the Desktop: `Godot_v4.7-stable_win64.exe` (+ `_console` variant for stdout).
- **Architecture:** composition + FSM. `player.gd` is a thin coordinator (owns a `MovementProfile`, a `StateMachine`, generic verbs). Phantoms are `Resource`s with 4 hooks (`get_movement_profile`, `modify_attack`, `perform_special`, `on_equip/unequip`) — adding one touches zero player code. `PhantomManager` swaps them in O(1) by repointing a profile. Skill trees = a `skills` dict on each Phantom.
- **Key design decision:** the **base kit (no Phantom) is the boot state** and the tuning target; Phantoms are *additive*, they don't fix a weak base. Tune `player/base_profile.tres` first; press `0` in-game to drop back to base. See `MOVEMENT_DESIGN.md`.
