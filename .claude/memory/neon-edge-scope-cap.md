The VIOLET EDGE **standard run caps at wave 30** — six bosses (Warden 5, Glutton 10, Slinger 15, Detonator 20, Pulsar 25, **The Phantom 30**); beating the Phantom = RUN COMPLETE. **There is no wave 31+.**

**The Phantom = "THE HAUNT"** (final boss; ⭐REDESIGNED 2026-07-22 — the user DROPPED the "channels all six previous bosses" concept after 2 reworks: "I'm not liking the way this boss is going… new mechanics for each [phase]"; they picked The Haunt from my proposals). A **spectral predator too arrogant to be touched**; the fight = stripping that arrogance. The **exception to "asteroids are the star."**
- **Core mechanic — INTANGIBLE:** shots pass through + its ghost-body is harmless to touch, EXCEPT it must **SURFACE to attack**: after each Sweep Ray it's solid/still/hittable for `PHANTOM_MATERIALIZE` (1.6s) — and lethal to touch. **Bait the ray, punish the window.** (`collisions` gate: hittable iff `vuln>0` or phase 3.)
- **Per-phase HP pool + RESET** kept: `PHANTOM_PHASE_HP=30`/phase; deplete → `transition` reset → next. Clear P3 → Victory (latched instantly). **Sweep Ray every phase, faster each** (telegraph ~1.7s, cooldown 4.6→3.5→2.4s).

(⛔NOT conjured-from-nothing — the user rejected that; it hunts an existing asteroid.) The vessel **homes at the ship + kills on contact** (`possessed_update`); gunfire chips its `PHANTOM_POSSESS_HP` (a hook in `collisions`); **break it → the Haunt is RIPPED OUT + surfaces** (`vuln`, the SAME punish path as P1's ray-recovery — shoot the exposed ghost to drain the pool) → dives into the next (`PHANTOM_DIVE_EVERY`).
