Copaimo is meant to reach **AAA quality** eventually, so always aim for the best
solution rather than the one that clears the reported fault. Stated by the user on
2026-09-01.

**Why:** the game is a years-long project ([[ranger-monster-game-concept]]) grown by
expansions ([[ranger-continents-expansion]]), so work that merely closes a symptom
accumulates as debt in code that has to hold up for years. The same bar already
applies to Violet Edge ([[neon-edge-quality-bar]]) — it is how this user judges
finished work across projects, not a one-off note.

**How to apply:** after the reported fault is fixed, ask what a player would still
notice and measure that too. Worked example from the day it was said: closing a
126 m gap where country roads ended in a meadow was the ask; checking the *transition*
afterwards found two cities where a raw dirt track met a fully kerbed street with the
whole gateway sequence skipped. The second fault was only found by asking "is this
actually good?" after the first was green — and it was the one a player would see.

Pairs with [[research-proven-solutions-first]] (a measured limit reported as a
tradeoff means I stopped researching too early) and [[test-after-building]].
