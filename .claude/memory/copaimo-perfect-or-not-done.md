Copaimo has to be the **highest quality**. If it is not perfect, do not consider it
done — and do not report it as done.

**Why:** said after a run where I kept committing work that passed 370 tests, a clean
audit and 36/36 driven routes, and then the user sent screenshots of walls floating
above the grass, walls holding back level fields, stairs nobody could climb and torn
paving. Green guards were measuring things that were true while the game looked
broken. "Its coming along but there are some quality standards that seem to be
slipping."

**How to apply:** a feature is finished when it LOOKS right in the game, not when the
suite is green. Before saying anything is done: load it with `--photo` at the actual
places the thing exists — at ground level, not only from the air — and look. If a
screenshot would embarrass me, it is not done. Say plainly what is still wrong rather
than leading with what passed; the user finds the faults in seconds either way, and
finding them for them is the job. See [[copaimo-aaa-quality-bar]],
[[ask-the-artefact-not-the-arithmetic]] and [[copaimo-look-at-the-game]].
