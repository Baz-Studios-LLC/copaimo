When a mechanic has an emergent, skill-gated consequence, the user prefers to LEAVE it for players to discover rather than making it always-on, explaining it in-game, or "fixing" it for casual players. Example: NEON DRIFT's octopus only gains small rocks to throw once you shoot its shield down, so passive players get pelted less — I offered to give it guaranteed throw-ammo; user declined: "I want skilled players to discover those kinds of things."

**Why:** emergent depth + mastery is a core design value for them; hand-holding cheapens the discovery.

**How to apply:** don't auto-smooth a tradeoff just because casual players might miss it. Surface the emergent behavior to the USER so THEY decide, but default to preserving discovery. Applies across their games ([[neon-drift-project]], [[spirit-spire-project]], CRASHOUT).
