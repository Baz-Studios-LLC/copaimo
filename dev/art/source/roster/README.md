# The roster guidebook

`Copaimo_Roster_Guidebook.pdf` — 49 pages, illustrated, describing the Copaimo
themselves. Brought in from outside the repository on 2026-09-26 when the machine it
sat on was being reset; it had been the only copy.

It is a **design reference**, not an asset. Nothing in the game loads it, and it lives
here rather than under `assets/` for the reason the root `.gitignore` gives at length:
the release workflows copy the whole asset tree, so anything left in there ships. Two
concept sheets at 4.3 MB were doing exactly that once.

Nothing in it has been built yet. The monsters are the half of this game that does not
exist — the world, its towns and the warden do, and the Copaimo do not — so treat this
as the brief for that work rather than as a record of anything in the build.
