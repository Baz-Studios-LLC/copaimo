# Sprite practice

`Sprite.aseprite` — an Aseprite file, kept for the same reason as everything else in
`source/`: it was outside version control on a machine about to be wiped, and it is
somebody's work rather than something a script can make again.

Aseprite files are authoring sources. If any of this ever becomes something the game
loads, the exported product belongs in `assets/`, and this stays here.
